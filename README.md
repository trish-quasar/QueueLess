# QueueLess

QueueLess is a web-based virtual queue and appointment management system developed for the Web Technologies course.

The system is designed for service environments where customers normally need to wait in physical lines. Customers can join a queue online, receive a digital token, track their position, and book appointments. Service staff manage queues from assigned counters, while administrators manage the overall system.

## Features

### Customer

- Register and log in
- View available services
- Join a service queue and receive a digital token
- Track queue status and number of people ahead
- View the currently serving token and assigned counter
- Cancel an active queue token
- Book and cancel appointments
- Check in from an appointment
- View queue and appointment history
- Edit profile information
- Upload a profile picture
- Change password

### Service Staff

- Log in to the staff dashboard
- View assigned counter and service
- Open or close the assigned counter
- View the current waiting queue
- Call the next token
- Recall a token
- Start serving a customer
- Skip a token
- Mark a service as completed
- View daily service history

### Administrator

- Manage services
- Manage service counters
- Create and manage staff accounts
- Activate or deactivate user accounts
- Assign staff members to counters
- Monitor active queues
- View service activity
- View operational reports
